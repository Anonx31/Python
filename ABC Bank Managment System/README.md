# 🏦 ABC Bank Management System

A simple command-line banking application built with Python. This project simulates basic banking operations such as checking account balance, depositing and withdrawing money, and managing KYC (Know Your Customer) documents.

## 📌 Features

* 💰 Check account balance
* ➕ Deposit money
* ➖ Withdraw money
* 🪪 Update KYC documents
* 📄 View KYC information
* 🚪 Exit the application safely

## 🛠️ Technologies Used

* Python 3
* Dictionaries
* Functions
* Loops
* Conditional Statements
* User Input Handling

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/ABC-Bank-Management-System.git
```

2. Navigate to the project folder

```bash
cd ABC-Bank-Management-System
```

3. Run the program

```bash
python bank_management.py
```
